# Документация проекта "Asteroid Dodge"

## Обзор проекта

**Asteroid Dodge** - это браузерная космическая игра, разработанная на React с TypeScript. Игрок управляет космическим кораблем, который должен уничтожать астероиды и вражеские корабли, избегая столкновений с ними. У корабля есть три жизни, и игра заканчивается, когда все жизни потеряны.

### Основные особенности игры:
- **Управление кораблем**: стрелки влево/вправо для движения
- **Стрельба**: пробел для выстрела
- **Жизни**: у игрока 3 жизни
- **Обязательное уничтожение астероидов**: пропуск астероида приводит к потере жизни
- **Вражеские корабли**: стреляют в игрока
- **Система очков**: за уничтожение врагов и астероидов
- **Звуковые эффекты**: лазеры, взрывы, потеря здоровья

### Игровой движок

#### Архитектура MVC
Игра построена по паттерну Model-View-Controller:

- **Model** (`model.ts`): содержит игровые данные (позиции объектов, очки, жизни)
- **View** (`view.ts`): отвечает за отрисовку игры на canvas
- **Controller** (`controller.ts`): обрабатывает логику игры, столкновения, спавн объектов

#### Основные классы

##### GameEngine
```typescript
class GameEngine {
  controller: GameController
  model: GameModel
  view: GameView
  
  start() // Запуск игрового цикла
  stop()  // Остановка игры
}
```

##### GameModel
```typescript
class GameModel {
  score: number           // Очки игрока
  countLife: number       // Количество жизней
  player: SpaceCraft      // Игрок
  bullets: SimpleBox[]    // Пули
  asteroids: Asteroid[]   // Астероиды
  enemies: Enemy[]        // Враги
  keys: { [key: string]: boolean } // Состояние клавиш
}
```

##### GameController
```typescript
class GameController {
  update(dt: number): boolean  // Обновление игровой логики
  spawnIfNeeded(timestamp: number) // Спавн новых объектов
  shootIfNeeded()             // Стрельба врагов
}
```

### Игровые объекты

#### SpaceCraft (Игрок)
- **Управление**: стрелки влево/вправо
- **Стрельба**: пробел
- **Анимация**: разные спрайты для движения влево/вправо
- **Столкновения**: круговая коллизия

#### Asteroid (Астероид)
- **Движение**: падение сверху вниз
- **Анимация**: вращение
- **Важность**: пропуск астероида = потеря жизни
- **Уничтожение**: выстрелом игрока

#### Enemy (Враг)
- **Движение**: падение сверху вниз
- **Стрельба**: случайные выстрелы каждые 2 секунды
- **Уничтожение**: выстрелом игрока

#### SimpleBox (Пуля)
- **Типы**: зеленые (игрока), красные (врагов)
- **Движение**: прямолинейное
- **Коллизия**: прямоугольная

### Система столкновений

#### Типы коллизий
1. **Прямоугольная** (`isRectanglesIntersect`): для пуль
2. **Круговая** (`isCirclesIntersect`): для игрока и врагов

#### Обработка столкновений
- **Игрок + враг/астероид**: игра окончена
- **Игрок + вражеская пуля**: игра окончена
- **Пуля игрока + враг/астероид**: уничтожение врага/астероида, +1 очко
- **Астероид + граница экрана**: потеря жизни

## Серверное приложение (Server)

### Технологический стек
- **Node.js** - среда выполнения
- **Express** - веб-фреймворк
- **Sequelize** - ORM для PostgreSQL
- **JWT** - аутентификация
- **Swagger** - документация API
- **CORS** - кросс-доменные запросы

### Структура сервера
```
server/
├── api/v1/             # API endpoints
│   ├── auth.ts         # Аутентификация
│   ├── user.ts         # Пользователи
│   ├── topics.ts       # Темы форума
│   ├── comments.ts     # Комментарии
│   └── theme.ts        # Темы
├── forum/              # Модели форума
├── theme/              # Модели тем
├── middleware/         # Middleware
└── index.ts            # Точка входа
```

### API Endpoints

#### Аутентификация
- `POST /api/v1/auth/login` - вход
- `POST /api/v1/auth/register` - регистрация
- `POST /api/v1/auth/logout` - выход

#### Пользователи
- `GET /api/v1/users/profile` - профиль пользователя
- `PUT /api/v1/users/profile` - обновление профиля

#### Форум
- `GET /api/v1/topics` - список тем
- `POST /api/v1/topics` - создание темы
- `GET /api/v1/topics/:id` - тема
- `GET /api/v1/comments` - комментарии
- `POST /api/v1/comments` - создание комментария

### База данных

#### Модели
- **User** - пользователи
- **Topic** - темы форума
- **Comment** - комментарии
- **Theme** - темы оформления

#### Связи
- User hasMany Topics
- User hasMany Comments
- Topic hasMany Comments
- Topic belongsTo User
- Comment belongsTo User
- Comment belongsTo Topic

## Развертывание

### Локальная разработка

1. **Установка зависимостей**:
   ```bash
   yarn bootstrap
   ```

2. **Запуск в режиме разработки**:
   ```bash
   yarn dev                    # Запуск клиента и сервера
   yarn dev --scope=client     # Только клиент
   yarn dev --scope=server     # Только сервер
   ```

3. **Сборка**:
   ```bash
   yarn build
   ```

### Docker развертывание

1. **Инициализация**:
   ```bash
   node init.js
   ```

2. **Запуск**:
   ```bash
   docker compose up
   ```

Сервисы:
- **nginx** (порт 80) - статика клиента
- **server** (порт 3001) - API сервер
- **postgres** (порт 5432) - база данных
